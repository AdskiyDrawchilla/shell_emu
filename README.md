# Эмулятор оболочки UNIX-подобной ОС

Практическая работа по разработке CLI-эмулятора командной строки. Программа работает полностью в оперативной памяти компьютера с виртуальной файловой системой (VFS), загружаемой из формата CSV.

## Исполнитель
* **Студент:** Мелентьев Владислав Евгеньевич

## Реализованная функциональность
* **Этап 1-2:** Интерактивный цикл REPL, парсер аргументов командной строки, логирование событий в CSV (`log.csv`).
* **Этап 3-5:** Загрузка структуры VFS из Base64 формата (`vfs.csv`). Реализация утилит: `ls`, `cd`, `pwd`, `who`, `rev`, `mkdir`.

## Инструкция по запуску
```bash
python emulator.py --vfs vfs.csv --log log.csv
```
